What is Balar FieldLog?
Mobile-first daily inspection logging and report approval system
👥 Everyone

FieldLog is a web app used by Balar Associates inspectors to log daily field observations, generate inspection reports, and route them through a digital approval process. All data is stored in Google Sheets; reports and PDFs are saved automatically to Google Drive.

📱 Inspectors
Log entries in the field, generate reports, and sign and submit for engineer review — from any phone or tablet.
🏗 Engineers
Receive a single email with a review link. Approve or reject with a comment — no login or account required.
☁️ Storage
Entries saved to Google Sheets. Signed PDFs filed in Google Drive by project, organized into Pending Review and Approved folders.
🔄
Approval Workflow
How a report moves from the field to final approval
👥 Everyone
Inspector Logs entries throughout the day
↓
Inspector Taps Generate Report — reviews in overlay, then taps ✍ Approve & Sign
↓
Inspector Confirms name in sign modal → submits
↓
System Converts report to PDF, saves to Drive (Pending Review), emails engineer
↓
Engineer Clicks review link from email — no login needed
↓
Engineer Reviews PDF on review page, then approves or rejects
↓
System Approve: final PDF saved to Approved folder, entries locked
↓
System Reject: inspector notified by email with engineer's comment, entries unlocked for editing

Logging In
First-time setup and returning access
👷 Inspector
1
First time on this device
Select your name from the dropdown and enter the 4-digit PIN. Your name is saved to the device — you won't need to select it again.
2
Returning visits
Your name appears automatically. Enter the PIN to continue.
3
Switching inspectors
Tap Not you? on the welcome screen to return to name selection.
⚠️
The PIN is shared across all inspectors. Do not share it outside Balar Associates field staff.

Daily Header
Project setup — required once per project per day
👷 Inspector

The daily header captures top-level information for a project on a given day. It must be posted before entries can be added. Working on multiple projects? Each gets its own header.

1
Select date, client, and project
Date defaults to today. Select the client first — the project dropdown then shows only projects for that client. The Post Daily Header button stays grayed out until both are selected.
2
Post Daily Header
Tap Post Daily Header. If a header already exists for this date and project it loads automatically. The button will briefly show Checking... while confirming with the server.
3
Daily Conditions
Enter weather and temperature. Tap Auto to detect weather from your GPS location. Tap Save Daily Conditions.
4
Daily Checklist
Check all items that apply for the day. Tap Save Checklist.
5
Equipment & Workforce
Add items using the dropdowns. Use Same as last time for this project to auto-populate from the most recent previous entry. If nothing is on site, check None on site today. Tap Update Equipment & Workforce.
💡
Same as last time searches backwards from the day before the active report date — works correctly even when logging past dates.
ℹ️
To work on a different project, tap Switch Project. Each project maintains its own header, entries, and report independently.
✏️
Adding Entries
Logging field observations throughout the day
👷 Inspector
1
Fill in the entry form
Enter time, station/location, description of work, and notes. Checklist items and weather can be added per entry if conditions changed.
2
Add a photo (optional)
Tap the photo area to take a photo or upload from your gallery. Photos are saved to Google Drive automatically.
3
Capture GPS (optional)
Tap Capture next to the GPS field to record your current coordinates.
4
Tap Add Entry to Log
Entry saved immediately. Repeat throughout the day. Entries can be edited using the pencil icon — except on pending or approved reports.
⚠️
If an entry fails to save, a red toast will appear with a Tap to Retry option. All failed entries must be resolved before a report can be generated.
📝
Daily Narrative
Optional summary of the day's work
👷 Inspector

The narrative section appears below the entry log. It allows you to write a free-form summary that will appear at the top of the generated report.

1
Type your narrative
Enter an overall summary of work performed. This is optional but recommended for complex or significant days.
2
Tap Save Narrative
Saves your narrative to the local cache. This allows you to save progress before the report is generated.
ℹ️
The narrative is saved locally when you tap Save Narrative. It is included automatically when the report is generated.
📄
Generating a Report
Creating the daily inspection report for review
👷 Inspector
1
Tap Generate / Review Report
Found at the bottom of the entry log. A modal will appear — select the date and project, then tap Generate.
2
Review in the overlay
The report opens full-screen within the app. Review all entries, equipment, workforce, checklist, and conditions carefully. Use the ← Close button to return to the app without signing.
3
Tap ✍ Approve & Sign when ready
The sign button appears in the top-right corner of the overlay. It is only available while the report is open — closing the overlay removes the option until you regenerate.
⚠️
Review the report carefully before signing. Once submitted, changes require the engineer to reject the report first.
✍️
Approve & Sign
Inspector sign-off and submission for engineer review
👷 Inspector
1
Tap ✍ Approve & Sign in the report overlay
The sign confirmation modal appears on top of the report. Your name is pre-filled from your login.
2
Confirm your name and tap Sign & Submit
A progress overlay appears while the report is converted to PDF, saved to Drive, and the engineer is notified.
3
Confirmation
A success message confirms submission. The overlay closes and the app returns to the entry view showing a yellow PENDING status banner.
📬
After signing, the engineer receives an email with a single button link to review the report. No further action is needed from you until the engineer responds.
🏷️
Report Status
Understanding the status banner
👷 Inspector

After generating a report, a status banner appears at the bottom of the entry view showing the current state of the report.

StatusWhat it meansCan you edit?
PENDINGReport submitted, awaiting engineer reviewNo — locked until engineer responds
APPROVEDEngineer has approved the reportNo — permanently locked
REJECTEDEngineer returned with commentsYes — correct and resubmit
⏳
While a report is Pending, all editing is locked — conditions, checklist, equipment, entries, and narrative are all read-only. The Generate Report button is also grayed out.
↩️
After a Rejection
What to do when an engineer sends a report back
👷 Inspector
1
Check your email
You receive an email with the engineer's comment describing what needs to be corrected.
2
Correct entries in the app
Navigate to the relevant date and project. All sections are unlocked — edit as needed.
3
Regenerate and resubmit
Tap Generate / Review Report, review the updated report, and tap Approve & Sign to resubmit. The engineer receives a new notification.
🔒
Locked Reports
What happens after engineer approval
👷 Inspector
🔒
Once approved, all entries for that project and date are permanently locked. Attempting to edit shows a message with the approver's name and timestamp. The View Approved Report button replaces the Generate button — tap it to open the final signed PDF.

If a correction is needed on an approved report, contact the project engineer directly. You can still switch to other projects and add new entries normally.

Engineer Review Page
The review interface
🏗 Engineer

Clicking the link opens a secure page showing:

Report Details
Project ID, project name, client, report date, and current status.
PDF Link
Button to open the signed PDF in Google Drive. Review before deciding.

Approve and Reject buttons fixed at the bottom of the page.

✅
Approving a Report
Finalizing with engineer sign-off
🏗 Engineer
1
Review the PDF
Open and read the full report. It includes the inspector's digital signature and timestamp.
2
Tap Approve
A confirmation modal shows your name. Tap Confirm Approval.
3
Done
Your signature block is added to the PDF and the file moves to the Approved folder in Drive. Entries are locked in the app.
🔒
Approval is permanent. Once approved, entries cannot be edited by the inspector.
❌
Rejecting a Report
Returning the report for corrections
🏗 Engineer
1
Tap Reject
A modal appears with a comment box. A comment is required.
2
Enter your comment
Describe clearly what needs to be corrected. This is sent directly to the inspector by email.
3
Tap Confirm Rejection
The inspector is notified immediately. Entries are unlocked for correction and resubmission.

Tips & Notes
Useful things to know
👥 Everyone
📅
Past dates: You can log entries and generate reports for past dates. Use the date selector in the report modal.
🔀
Multiple projects same day: Use Switch Project to move between projects. Each has its own header, entries, and report.
📁
Drive folder structure: Reports are filed as [Project Number] - [Client] - [Project Name] / Pending Review or / Approved. Filenames: YY.MM.DD Field Report - Client - Project Name - Number.pdf
📶
Internet required: FieldLog requires an active connection to save entries, generate reports, and submit for review.

Troubleshooting
Common issues and how to resolve them
👥 Everyone
IssueWhat to do
Post Header button stays grayed outMake sure both a date and a project are selected. The button enables only after both are confirmed.
Post Header shows "Checking..." for a long timeCheck your internet connection. The app is verifying with the server whether a header already exists.
Generate Report button is grayed outThe report is either Pending or Approved. A pending report must be resolved by the engineer first.
✍ Approve & Sign button not visibleThe report overlay must be open. Close it with ← Close and tap Generate again to reopen.
Report submission fails with an errorCheck your connection. Verify the engineer's name in the Projects tab matches the Engineers tab exactly.
"Same as last time" finds nothingNo previous header with valid equipment or workforce exists before this date. Add manually.
Duplicate entries visible in the logSwitch to a different project and back — this triggers a fresh sync and removes duplicates from the display.
Review link says "Invalid or expired token"Use the link directly from the original email without copying and pasting.
Engineer name shows "Unknown Engineer" on review pageName in Projects tab doesn't match Engineers tab exactly. Check spelling and punctuation.
Entry shows locked incorrectlyGenerate the report for that date/project to refresh the status. Contact the administrator if still incorrect.
